# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique**. Utilisez le signalement privé de GitHub : onglet **Security → Report a vulnerability** de ce dépôt. Nous accusons réception sous 72 h.

## Périmètre

Ce site est une démonstration : son backend est simulé dans le navigateur, et aucune donnée réelle n'est traitée. Les limites connues et assumées (base modifiable par le visiteur, session lisible par JavaScript, paiement fictif) sont listées dans [docs/08-securite.md](docs/08-securite.md#3-limites-assumées-de-la-simulation) et ne constituent pas des vulnérabilités. Tout le reste nous intéresse.
